## The icon renders

These are **renders, not drawings**. Each icon is parametric geometry lit by a fixed
three-light rig, rendered headless in Blender, and downsampled by whole-number
factors. The manifest records, per icon:

* the Blender **version and build hash** that made the pixels (any Blender 5.x is
  accepted, so a re-render on a later build will not reproduce them — the point of
  recording it is that a difference is *visible* rather than silent);
* the **OpenPBR parameters** it was authored with, the **shader input** each one
  mapped onto, and the **deviations** between the OpenPBR specification and the
  shader Blender actually implements (Blender 5.3 Alpha has no OpenPBR node and no
  MaterialX operators — upstream issue #145127 — so "OpenPBR" is kept as a
  parameter table plus a per-icon record of where it could not be honoured);
* the **rig**, the render size and the downsample factors;
* per-size **hash** and **measurements** (ink coverage, mean and peak luminance,
  chromaticity).

The hash is an integrity check — this file is the file the manifest describes. It is
**not** a signature and not a security mechanism, and the manifest says so itself.

## What is deliberately *not* shipped

* **No raster textures.** Materials are named solid fills derived from the OKLCH
  token table, and geometry. Where the design doctrine asks for real material
  textures, the absence is stated rather than filled with generated noise.
* **No fonts.** Faces are discovered by cosmic-text from the operating system at
  runtime and never redistributed; Glyphon owns shaping, fallback, and its runtime
  etagere atlas.
* **No sampled audio.** Sound, when it lands, is synthesised rather than sampled,
  which sidesteps the licence gate rather than satisfying it.
